Simulation replay

pm-signal-engine

An event-driven trading engine for 15-minute crypto prediction markets. It prices each contract from the live underlying and buys when the order book hasn't caught up yet. Everything on this page comes from a seeded simulator. The engine is a clean-room template of a system I ran from December 2025 to April 2026.

Summary

Replay a market

Pick a market and press Play. The blue line is the engine's fair price, computed from the live underlying. The gray band is the order book's best bid and ask. The engine trades when blue leaves the band and the book is slow to follow. The lens zooms to 45 seconds either side of the cursor, where the lag is visible.

Inside the engine

Every event goes through one loop: update state, evaluate signals, combine, size, check risk, send. These counts are from the gated run.

Decay monitor, ungated run

It judges each signal per regime on markouts. A signal confidently below zero is switched off for six hours, then gets a fresh trial.

    Run it yourself

    # standard library only, Python 3.10+ pip install -e ".[dev]" python -m pmbot.cli # two simulated days, text report python -m pmbot.cli --no-regime # trade every hour and compare python -m pmbot.demo --seeds 10 # rebuild this page pytest

    Simulated data. The simulator's parameters are invented so each mechanism is visible, so none of these numbers describe real markets. The production system's code, tuned parameters and account lists are not part of this repository.
